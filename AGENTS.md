# Repository instructions

## Pull requests

Every PR must update the in-app changelog in `app/LandinhoLib/Sources/BetaSheet/BetaSheet.swift` in the same change.

- Summarize the PR's changes in `latestRelease` with concise Brazilian Portuguese bullets. Include relevant app, backend, and Telegram changes; describe internal-only changes as maintenance.
- Add or amend a dated entry (`DD/MM/YYYY`), keeping the newest changes first and preserving existing history.
- Review `issues` and `nextSteps` so resolved problems and completed features are reflected accurately.
- Verify the changelog against the final diff before opening or updating the PR.
